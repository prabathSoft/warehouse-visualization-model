📘 README — Warehouse Geo‑Mapping Platform (WGMP)

Warehouse Geo‑Mapping Platform (WGMP)

A single-page tool that turns the Inventory – Count of Storage Boxes CSV export into an interactive map of the warehouse: hall and aisle overviews, shelf-by-shelf rack views, possible empty locations, merchant density heatmaps, consolidation analysis and a true-scale 3D model of the halls.

  • Built for: FC BER3 inventory team (cycle counts, slotting, consolidation, space checks)
  • Delivered as: one self-contained HTML file (WGMP - Warehouse Geo-Mapping Platform.html), also published as a claude.ai artifact
  • Data source: the CSV you upload each time you open it — nothing is uploaded to a server and nothing is stored

1. Quick start

  1. Export Inventory – Count of Storage Boxes as CSV (file name like Inventory-_Count_of_Storage_Boxes_29-10-2026.csv).
  2. Open WGMP (the artifact link or the HTML file in Chrome / Edge / Firefox).
  3. On the Upload Inventory CSV screen, click the 📂 area or drag the CSV onto it.
  4. The progress bar fills and the platform opens on Aisle Overview.
  5. To load a newer export later, click ⟳ Attach updated CSV at the bottom of the left sidebar.

WGMP asks for the CSV every time it is opened. Always attach the latest export so the views reflect the current stock.

2. The CSV file

Columns (A–J)

Col Header Used for
A storage_boxes Storage box number (links to Hive)
B merchants Merchant name
C skus SKU number (links to Hive)
D sku_description Product description
E pickable_type pickable, non_pickable, bulk_pickable
F tracking_code Batch / tracking code
G expiry_date Expiry, e.g. May 31, 2029
H storage_location Location code (see section 3)
I quantity Units in the box
J storage_box_type e.g. Storage Pallet (150x80x120)

Optional extra columns

Newer exports (Count of storage boxes – with block status – last shipped) carry four more columns. They are matched by header name, so their position doesn't matter; if they're missing, the related filters simply don't appear.

Header Used for
box_status Blocked / Not blocked
block_reason e.g. blocked on inventory batch, investigation, blocked on sku
block_notes Free text (e.g. Expired, Quality defect) — searchable
last_shipped_date_sku Date and time the SKU last shipped, e.g. August 19, 2026, 08:51; empty = never shipped

Rules

  • With a header row (normal export): columns are matched by name, so their order does not matter.
  • Without a header row: WGMP reads the fixed A–J order above (location in column H). It also accepts the older WGMP layout with the location in column A.
  • Separators: comma (standard export), semicolon (CSV re-saved from German Excel) or tab are detected automatically.
  • Encoding: UTF-8 or Windows/ANSI (Excel) — umlauts are read correctly either way.
  • Blank lines are ignored. Straight quotes or < > in merchant names are shown as typographic quotes / ‹ › so they can't break the page.
  • One row = one storage box / SKU combination. A location can appear on several rows.
  • Required headers: storage_boxes, merchants, skus, sku_description, pickable_type, storage_location, quantity, storage_box_type. tracking_code and expiry_date are optional.
  • If something is wrong, a red box on the upload screen names the problem (for example the missing columns).

Halls and floors

Forklift paths (no rack)

Some locations have no racking because forklifts drive through them. They are set in the page as NO_RACK:

Hall / Floor Aisles Shelf Levels Use
H1-F1 002 – 033 07 A, B, C Forklift path

These slots are never counted as possible empty locations. They show as yellow hatched slots in the Aisle View and Storage Map. In 3D they have no beams at A–C and a yellow floor strip labelled 🚜 Forklift path; the racks above (level D up) bridge the tunnel.

Drop zones

Codes such as H1-F1-DROP001 (red card in the diagram above) are common-area drop locations. They are not part of the rack views, empty-location estimate or 3D model.

4. Screen layout

  • ◐ (top of the sidebar) switches light / dark mode. The choice is remembered in your browser.
  • Data as of shows the date taken from the CSV file name; the WGMP logo sits just below the title.
  • KPI tiles: storage boxes, locations, aisles, units, SKUs, merchants — always for the current filters.

5. Left sidebar: search, box finder and filters

The sidebar filters apply to every tab (with the exceptions noted per tab). Combine as many as you like; each section has a clear link.

Non-matching stock is faded, not hidden, in the rack views (Storage Map, Aisle View) so you never mistake a filtered-out slot for an empty one.

6. Tabs

6.1 Aisle Overview

The starting page.

  • Old stock KPI (boxes whose SKU hasn't shipped for > 180 days or never) — click it to list those boxes in Storage Boxes. Blocked boxes KPI next to it.
  • KPIs: storage boxes, occupied locations, aisles with stock, expired rows, rows expiring ≤ 90 days, rows in drop/other zones, and possible empty locations (shown by default; hide them with the Show possible empty switch).
  • Box-type bar: share of each storage box type.
  • Aisle tiles grouped by hall/floor. Shading = occupied locations matching the filters; the thin strip = box-type mix; a red ! = expired stock in the aisle; grey "N empty" = possible empty locations (shown by default).
  • Drop zones / other locations: chips for DROP and non-standard codes; click one to see its boxes in Storage Boxes.
  • Click a tile → Aisle View of that aisle.

6.2 Storage Map

The original WGMP map.

Aisle grid (per hall)

  • Hall buttons at the top (H1-F1, H1-F2, H2-F1, H2-F2) and a breadcrumb.
  • Aisles grouped by number zone (000–099, 100–199 … 1000+), coloured light → dark blue → orange by box count. Plain outlined tile = no boxes. Grey "0 match" = aisle has stock but none matches the filters. Search matches blink orange.
  • Drop Zone cards (red) per hall: boxes, units, merchants, BULK badge above 20 boxes. Click a card for its box cards.

Shelf view (click an aisle)

  • Rows = levels (A ground, top level first), columns = shelves split into column positions.
  • Slot colour = merchant colour; stronger = more units. Amber pulsing = zero stock. Outlined, no fill = empty. Dashed grey = N/A. Faded = doesn't match sidebar filters.
  • Merchants in aisle list on the left: click a merchant to highlight their slots (others dim); click again or All Merchants to reset.
  • Hover a slot → dark info card (box, merchant, SKU, name, qty, box type, status, tracking, expiry).
  • Click a slot → bottom detail panel with one card per box. Box and SKU numbers link to fc.hive.app. Press Esc or ✕ to close.
  • Click a Shelf N header → shelf detail panel (every level and column of that shelf).
  • Zone A / Zone B badge for H2-F1 aisles.

6.3 Aisle View

Same shelf-grid style as the Storage Map, plus extra tools.

  • Aisle picker with ◀ ▶ buttons and Storage Map ↗ to open the same aisle in the Storage Map.
  • KPIs: occupied slots, storage boxes, units, possible empty, slots matching filters, expired rows.
  • Colour by: Merchant (default; stronger = more units, amber = zero stock) · Box type · Pickable · Expiry · Last shipped (a slot takes the colour of its oldest SKU) · Blocked.
  • Outlined slots with no fill = possible empty (same estimate as the Empty Locations tab). Red inner border = slot holds expired stock.
  • Merchant list on the left (highlight one merchant; resets when you change aisle).
  • Hover = info card; click a slot = detail cards with Hive links; click an empty slot = usual box type and size for that level; click Shelf N = every box on that shelf with its location.
  • Opening a location from Empty Locations or the 3D View highlights that bay/level and shows its contents.

6.4 Storage Boxes

All rows matching the filters as a table.

  • Columns: box, location, merchant, SKU, description, qty, last shipped (date + days, coloured by age, or never), status (blocked + reason), box type, pickable, tracking, expiry (with expired / soon tags).
  • Sort by Last shipped to put the oldest stock first.
  • Click a column header to sort (click again to reverse). 300 rows shown first; Show more loads 500 at a time.
  • Click a location → Aisle View at that bay/level.
  • Copy rows (TSV) copies the filtered table to paste into Excel / Sheets.

6.5 Empty Locations

List of possible empty locations (see section 7.1).

  • KPIs: total, per hall/floor, aisles with gaps.
  • Bar of the usual box type of the empty slots.
  • Aisles with the most possible empty locations (top 10).
  • Table: location, hall/floor, aisle, bay, level, position, usual box type, size (H × L × W cm). Sortable by location, level or box type.
  • Click a location → Aisle View with that slot highlighted.
  • Copy list (TSV) for Excel.
  • Filters that apply: Hall/Floor, Box type (the usual box at that level) and Search. Merchant, pickable and expiry filters do not apply (these slots hold no stock).

6.5b Blocked

A dashboard of every row with box_status = Blocked, built from box_status, block_reason and block_notes (needs the with block status export; with older files the tab says so).

  • KPIs: blocked boxes, % of all boxes, units, SKUs, merchants, aisles, how many are expired and how many hold SKUs not shipped for > 180 days / never.
  • Breakdowns (click a bar to drill down, click again or clear to go back; drill-downs combine):
  • Block reason — e.g. inventory batch, investigation, sku, batch expiry date reached, request. Rows with several reasons count in each.
  • Block notes (grouped) — similar notes are merged: all Asana links → Asana task link, "Automatically blocked: batch expired on …" → Auto-blocked, the different spellings of "new goods, waiting for old stock" → one group, etc.
  • Top merchants, Hall / Floor, Box type, SKU last shipped.
  • Aisles with most blocked boxes — click to open the aisle in the Aisle View.
  • Table of the blocked rows: box, location, merchant, SKU, description, qty, reason badges, notes (Asana links open the task), last shipped, expiry. Sortable; Copy rows (TSV) for Excel.
  • The sidebar filters apply (hall/floor, merchant, box type, expiry, last shipped, search); the sidebar Box status filter is ignored on this tab.

6.6 Density Heatmap

The original WGMP merchant density heatmap.

  • Metric: Boxes · Quantity · % of Aisle.
  • Merchant list on the left (search box at top right). All Merchants = overall density; click a merchant to see only their density.
  • One tile per aisle, grouped by hall/floor, blue (low) → yellow → red (high), scaled within each hall/floor. Grey = no stock. Zone A/B borders in H2-F1.
  • Hover a tile = top 5 merchants with share; click = open the aisle in the Storage Map.

6.7 Consolidation

How spread out each merchant is.

  • Summary: pure aisles (one merchant), mixed aisles, scattered merchants (> 3 aisles), average aisles per merchant.
  • By Merchant: card per merchant with boxes, units, aisles, consolidation score and the aisles they use (strongest first). Click an aisle chip → Storage Map.
  • Aisle Purity: every aisle sorted by the dominant merchant's share, with the merchant mix bar.
  • Floor Plan: per hall, columns = aisles, rows = levels F–A, coloured by the dominant merchant. H2-F1 is split into Zone B, Zone A and corridors.

Score rules are in section 7.4.

6.8 Summary

One line per aisle: locations, boxes, units, SKUs, merchants, non-pickable rows, expired rows, main box type and box-type mix. Click an aisle to open it.

6.9 3D View

A true-scale 3D model of the stock. Needs an internet connection (3D library).

Layout

  • Each hall is a separate building (outline + "Hall 1" / "Hall 2" label) with a gap between them.
  • F1 = ground floor; F2 sits on a see-through slab directly above F1 of the same hall (F3 would go above F2). Floors are labelled, e.g. H1-F1 · Ground floor, H1-F2 · Level 2.
  • Every occupied location is a block at its real box size, placed at its aisle, shelf, level and position, inside steel pallet racking: charcoal uprights (9 × 9 cm) at every shelf boundary and galvanised-grey beams (12 cm high) under each level and on top. The racking is kept neutral so the box colours stay readable.
  • H1-F1 real aisle arrangement: aisles 001–033 stand in back-to-back pairs (3 m aisle, 0 m, 3 m, 0 m …), 5 m between 033 and 034, and aisle 035 runs crosswise across the far end of 001–033 (see 7.5).
  • Sidebar filters apply: matching locations keep their colour, others become faint outlines.

Mouse

  • Drag = rotate · right-drag / Shift-drag = pan · scroll = zoom
  • Hover = box details · click = detail panel with Open in Aisle View · double-click = zoom to that block

  • Hover in Heat mode also shows the aisle's boxes, units and % of aisle.

Merchant colour — blocks in merchant colours (same as the rack views); the legend lists the 10 biggest merchants on screen.

7. How the numbers are worked out

7.1 Possible empty locations

The export lists only occupied locations, so empty ones are estimated from each aisle's own pattern:

  1. Shelves: every shelf number used in the aisle; gaps of up to 2 missing shelves between used ones are filled in.
  2. Levels: every level used in the aisle.
  3. Positions per level: the highest position number that appears at least twice, or in at least 3 % of that level's locations (whichever is larger). Single outliers (e.g. one /32) do not create hundreds of fake empties.
  4. Forklift paths (see 3) are left out.
  5. Every other slot in that pattern with no box in the export = possible empty. Its usual box type = the most common box type on that level of the aisle.

These are candidates. Always confirm on the floor before using a location.

7.2 Expiry status

Status Rule
Expired expiry date before today
≤ 90 days expires within the next 90 days
> 90 days later
No expiry empty or unreadable date

7.3 Density

  • Boxes / Units per aisle: count of matching boxes / sum of units in the aisle.
  • % of aisle: matching boxes ÷ all boxes in the aisle (with one merchant selected = that merchant's share).
  • Colours are scaled to the highest value within each hall/floor.

7.4 Consolidation score and purity

  • Consolidation score = 100 × (1 − (aisles used − 1) ÷ (total aisles − 1))
  • ≥ 80 % green — well consolidated · 50–79 % amber — moderate spread · < 50 % red — consolidation recommended
  • Scattered merchant: stock in more than 3 aisles.
  • Aisle purity = dominant merchant's boxes ÷ all boxes in the aisle. ≥ 90 % green · 60–89 % amber · < 60 % red.
  • Drop zones are excluded.

7.5 3D geometry

Item How it's drawn
Box real size from the box type, H × L × W (cm)
Shelf (bay) length longest level in that shelf: sum of box lengths + 6 cm gaps (min 0.8 m)
Level height tallest box on that level + 18 cm clearance + 12 cm beam
Racking uprights 9 × 9 cm at every shelf boundary · beams 12 cm high × 10 cm deep under each level and along the top
Aisle spacing 1.8 m corridor (standard)
H1-F1 aisles 001–035 001–033 in back-to-back pairs: 3 m after 001, 0 m between 002·003, 3 m after 003 … up to 033 · 5 m between 033 and 034 · 035 runs perpendicular, across the far end of 001–033 (3 m clearance). All other H1-F1 aisles keep the standard spacing.
Floor-to-floor height tallest rack on the floor below + 2.5 m (min 3 m)
Gap between halls 25 m

The export has no real rack or building measurements, so these are worked out from the boxes.

10. Daily workflow examples

Find a box quickly — type the number in Find storage box → Enter → the slot is highlighted with its details and Hive links.

Plan a cycle count for one merchant — tick the merchant in the sidebar → Storage Boxes → sort by location → Copy rows (TSV) → paste into your count sheet. Check Consolidation to see how many aisles you will walk.

Find free space for inbound pallets — Hall/Floor = H2-F1, Box type = Pallet → Empty Locations → sort by location → copy the list; verify on the floor.

Find old / slow-moving stock — sidebar → Last shipped → Show old stock → Storage Boxes → sort by Last shipped (oldest first) → Copy rows (TSV). Aisle View or 3D View → colour by Last shipped shows where it sits (red = > 1 year, purple = never shipped).

Check blocked boxes — open the 🚫 Blocked tab → click a reason or note group to drill down → Copy rows (TSV).

Check expired stock — Expiry = Expired → Aisle Overview (red ! tiles) → Storage Boxes for the list → Aisle View (Colour by Expiry) to see where it sits.

Walk a merchant's route — tick the merchant in the sidebar → 3D View → 🎥 → 🚶 Walk; the tour visits only their aisles.

Show a merchant's footprint — 3D View → ◧ Layers → 🔥 Heat → pick the merchant in the Merchant density list → % of aisle.

Compare halls — 3D View with no filters → ⌂ (fly home); both buildings and their floors are shown side by side.

11. Known limitations

  • Empty locations are estimates (the export has no slot master). Aisles with unusual layouts can over- or under-report.
  • 3D sizes of racks, floors and halls are derived, not measured. Only H1-F1 aisles 001–035 use the real arrangement; all other aisles use a standard 1.8 m spacing. F2 aisles are placed at the start of the hall because the export has no position for them on the upper floor.
  • XL boxes have no size in the data (drawn 40 × 40 × 40).
  • Storage Map "Blocked (wide box below)" shading from the original WGMP is listed in the legend but not applied — enabling it would draw neighbouring pallets on top of each other with this data.
  • The description shown in Storage Map cards/tooltips is shortened to 50 characters (full text in Aisle View and Storage Boxes).
  • Very large files (> ~100k rows) work but the 3D View and Storage Map get slower.
  • Nothing is saved: each session starts from the CSV you attach.

12. Troubleshooting

Problem Fix
Red "Missing columns" on upload Use the Count of Storage Boxes export, or make sure the A–J order in section 2 is used without a header.
Numbers look too low Check the sidebar for active filters (KPIs follow the filters); use clear.
3D View says the library could not load It needs internet access to cdn.jsdelivr.net; reload when online. Other tabs work offline.
3D view is empty / lost Press ⌂ in the centre of the move pad, or ◧ Layers → ◇ Isometric.
Hive links don't open You must be logged in to fc.hive.app in the same browser.
Copy button says "blocked" Your browser blocked clipboard access; allow it or select and copy manually.
Wrong date in the sidebar The date comes from the file name (DD-MM-YYYY); rename the file if needed.

13. Technical notes

  • Single HTML file, no installation, no server. Tested in Chromium; current Chrome, Edge and Firefox are supported.
  • CSV is read locally in the browser (FileReader); no data leaves your computer.
  • External resources: Google Fonts (JetBrains Mono, Syne) and three.js 0.147 + OrbitControls from cdn.jsdelivr.net (3D View only).
  • Browser storage: only the light/dark choice (wgmp_theme).
  • Hive deep links: https://fc.hive.app/storage-boxes/<box> and https://fc.hive.app/inventory/details/<sku>.
  • Code structure: the original WGMP engine (Storage Map, Density Heatmap, Consolidation, box search) runs alongside the newer views; both are fed from one parse of the CSV and share the sidebar filters.
